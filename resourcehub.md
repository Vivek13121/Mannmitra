# 📚 Resource Hub – Article Integration Plan

## 🎯 Goal
Enhance **MannMitra → SIH Prototype** by providing **evidence-based articles** for students on topics like sadness, anxiety, and depression.  
Instead of storing content in our DB, we will **link to original sources** 

---

## 🛠️ Implementation Steps

### 1. New Section: Recommended Reads
- Add a **“Recommended Reads”** section in the **Resource Hub** page.
- Display article cards (Title + Emotion tag + Short description).
- Each card links externally (opens in a new tab).


### 3. UI Layout
- Use **card-based layout** with:
  - Title (clickable link)
  - Emotion/topic tag (badge)
  - 1-line description
- Add **"Read More"** button → Opens external source.

### 4. Prototype Priority
- Keep it **simple but functional** for hackathon demo.
- Later expansion: regional language articles, govt PDFs.
